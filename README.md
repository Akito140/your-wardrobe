# Your Wardrobe — Stylo

Мобильный демонстрационный прототип магазина одежды Stylo (HTML, CSS, vanilla JS). Главный экран — каталог отдельных вещей; готовые образы, гардероб и профиль размеров находятся в дополнительных вкладках.

**Live site:** https://akito140.github.io/your-wardrobe/

## Функции прототипа
- Каталог отдельных вещей: поиск, категории, крупные карточки, описание материала и кроя, демо-контакт продавца.
- Кнопка «Заказать» открывает демонстрационный выбор размера и цвета; никакая заявка продавцу не отправляется.
- Подборка из пяти готовых образов находится во вкладке «Образы». Для «Городского гранжа», «После полуночи», «Уличного комфорта» и образа с бордовым пальто доступны подготовленные full-body фотографии результата.
- При примерке выбранное фото отображается в локальном превью; результат привязан к образу. Это интерфейсная симуляция, а не AI-генерация.
- Нижние вкладки: каталог, гардероб, образы и профиль.
- Профиль: фото для макета, рост, стандартные размеры одежды и обуви, дополнительные мерки в сантиметрах.
- Поиск, фильтрация, добавление и удаление вещей в гардеробе.
- Параметры, избранное и вещи гардероба сохраняются в `localStorage` браузера. Фото для примерки хранится в `sessionStorage` только до закрытия вкладки; фото вещей из пользовательского гардероба не сохраняются после перезагрузки.

## Ограничения
Каталог, цены, материалы, продавцы, контакты и размерные варианты — демонстрационные примеры. Контакты используют домен `example.com`; реальные продавцы не подключены. Форма заказа только показывает выбранные параметры и ничего не отправляет. «Генерация» примерки — заранее подготовленное изображение, которое не меняется в зависимости от выбранного фото; для остальных образов показывается SVG-иллюстрация. Файл фото используется только для локального превью и не отправляется на сервер. Для настоящего AI try-on потребуются отдельный backend, API-провайдер и его кредиты. Размеры служат только демонстрационным профилем, таблицы размеров разных брендов отличаются.

Чтобы добавить готовый результат для нового образа, положите файл в `assets/images/looks/` и укажите имя в свойстве `resultImage` соответствующего образа в `assets/js/app.js`.

## Кредиты
Bootstrap 5.3.3 (MIT, CDN jsDelivr). Шрифты Golos Text и Unbounded (SIL OFL, Google Fonts). Иллюстрации примерки и интерфейсные иконки нарисованы для проекта как SVG. Изображения одежды и примерки подготовлены из референсных фотографий, предоставленных для этого макета.
